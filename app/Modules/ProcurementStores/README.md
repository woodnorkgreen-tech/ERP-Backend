# Procurement & Stores Module Documentation

This module provides a comprehensive system for managing warehouse inventory (Stores) and the supply chain lifecycle (Procurement). It is built using a **Modular Monolith** architecture, ensuring total isolation of logic and assets.

---

## 🏗️ Architecture Overview

The module follows a "Complete Encapsulation" pattern where both backend and frontend components are grouped by domain rather than type.

### 🔙 Backend (Laravel Modules)
**Path:** `backend/app/Modules/ProcurementStores/`

| Component | Responsibility |
|-----------|----------------|
| **ServiceProvider** | Registers the module, loads migrations, and binds API routes. |
| **Routes** | Defines all endpoints under the `/api/procurement-stores` prefix. |
| **Controllers** | Handles HTTP requests and delegates to Services. |
| **Models** | Eloquent models for Suppliers, Stocks, and Purchase Orders. |
| **Database** | Contains module-specific migrations and seeders. |

### 🎨 Frontend (Vue.js Modular)
**Path:** `frontend/src/modules/procurement-stores/`

| Component | Responsibility |
|-----------|----------------|
| **Views/** | Contains the UI for Stores (Dashboard, Check-ins) and Procurement (Suppliers, POs). |
| **Routes** | Modular route definitions integrated into the `MainLayout`. |
| **Composables/** | Shared logic for fetching stock levels and managing vendor data. |

## 🛠️ Implementation Details

### 1. Backend Registration
The module is activated via the `ProcurementStoresServiceProvider.php`. It is registered in `backend/bootstrap/providers.php`:

```php
// backend/bootstrap/providers.php
return [
    // ...
    App\Modules\ProcurementStores\Providers\ProcurementStoresServiceProvider::class,
];
```

### 2. API Connectivity
All endpoints are automatically protected by `auth:sanctum` and prefixed.
- **Base URL:** `/api/procurement-stores`
- **Example:** `GET /api/procurement-stores/test`

### 3. Frontend Routing & Layout
Routes are wrapped in the `MainLayout` to provide a consistent sidebar and header experience:

```typescript
// frontend/src/modules/procurement-stores/routes.ts
export const procurementStoresRoutes: RouteRecordRaw[] = [
  {
    path: '/',
    component: () => import('@/layouts/MainLayout.vue'), // Main Layout Wrapper
    children: [
       { path: '/stores', ... },
       { path: '/procurement', ... }
    ]
  }
]
```

### 4. Sidebar Integration
Navigation items are dynamically injected based on user roles through the `useRouteGuard.ts` composable, ensuring that only users with the correct permissions see the module links.
