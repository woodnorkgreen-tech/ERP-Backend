(`03_WNG_FINANCE_DECISION_REGISTER.md`, confirmed/added 2026-09-23) against the current codebase.
**No code changed as a result of this document.** STAB-7's own technical detail is not repeated
here — see `14_STAB_7_PETTY_CASH_TRIPLE_POSTING_ANALYSIS.md` through `16_STAB_7_VERIFICATION.md`.

**FACTUALLY RESOLVED** / **BLOCKED BY BUSINESS DECISION** / **BLOCKED BY ACCOUNTING DECISION**.

## What this means for Phase 2B

- W3-5 and W3-6 mirror W2-5/W2-6 almost exactly in shape — if Phase 2B builds a shared
  "duplicate-detection" or "return for correction" mechanism for procurement, the same mechanism
  should very likely serve the petty-cash side too, rather than building two parallel copies.
- W3-2 and W3-8 are sequential, not independent: W3-8's GL-recovery question only becomes
  answerable once W3-2's payout-side GL treatment is settled, since both concern how (or whether)
  a Staff Advances receivable account should ever appear on the books at all.
- W3-4's evidence-standard decision should be made once, and applied consistently to both W3-4
  (petty cash) and W2-2 (supplier bills) where the same attachment mechanism could plausibly serve
  both — Phase 2B should check whether one generic mechanism can cover both before building two.
- W3-7 is the smallest and narrowest of the open items technically, but is explicitly left to WNG
  rather than defaulted, since the current gap has existed without incident and building a fix
  before confirming it is needed could just as easily be premature effort.
