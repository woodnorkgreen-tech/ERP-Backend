## What this means for Phase 2B

- W7-1A (casual/technical) is the lowest-effort, most concrete starting point: it extends a working
  system (`JobCard`) rather than building a new one, and its rate source (`TechnicalLabour.day_rate`)
  already exists.
- W7-1B (permanent crew) requires building the crew/team concept from nothing — a materially larger
  effort than W7-1A, and should not be assumed to ship in the same phase.
- W7-3/W7-12 (rate methodology) is the one decision every other capability-building item depends on
  — resolving it first avoids building a calculation twice.
- The reconciliation invariant (W7-14) should reuse `splitGrossByLabourClassification()`'s existing
  department-level totals as its authoritative "labour cost pool" figure, not a newly separately
  computed one.
