## What this means for Phase 2B

- W2-3 and W2-5 both touch the Bill creation/validation path and should be designed together —
  building staged billing without duplicate detection would make a duplicate easier to slip in
  across multiple legitimate-looking partial bills.
- W2-4 and W2-6 are closely related but must stay two separate mechanisms: W2-6 corrects an order
  that was never approved; W2-4 amends one that was. Building only one risks someone routing a
  pre-approval correction through the post-approval amendment flow (or vice versa) for convenience.
- W2-1's senior-approval tier is the only W2-1–W2-6 item with zero data-model complexity — it is
  purely blocked on Management/Procurement supplying a number and a name.
- W2-7 through W2-10 are not yet scoped at all; none should be estimated for Phase 2B until WNG
  responds to `11_W2_PROCUREMENT_DECISION_BRIEF.md`.
